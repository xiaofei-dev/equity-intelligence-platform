# Long Horizon v1.1 Tier-1 Retrospective

## Scope

This retrospective evaluates separately versioned Long Horizon v1.1 targets:
business quality, security attractiveness, expected return, and downside risk.
It preserves each target's applicability and missing-data rules and does not
manufacture a combined score when a required target is unavailable.

The run is current-universe retrospective development evidence. It is not
strict PIT validation and does not prove future investment performance.

## Publication boundary

Historical fundamentals, market values, prices, security outcomes, returns,
drawdowns, and target statistics remain in Git-ignored controlled storage.
Public documentation records methodology, versions, hashes, counts, evidence
labels, and limitations only.

Tests that require the controlled ledger skip explicitly in a clean clone.
Pure Long Horizon formula, applicability, chronology, and contract tests
remain mandatory.

See [Licensed Market Data Publication Policy](licensed-market-data-publication-policy.md).
